# CJM — Chute

| Stage | Doing | Thinking | Feeling | Friction we must remove | Our move | Success signal |
|---|---|---|---|---|---|---|
| **1. Discover** | Sees a 20-second demo on X/HN: 8 files → XML bundle → pasted into Claude | "That is the exact thing I do 30 times a day" | Recognition | Generic utility positioning reads as noise | Demo shows the *agent loop*, never a feature list | Click-through > 4 % |
| **2. Evaluate** | Reads the landing page, checks the price, looks for telemetry | "Is this another $30/yr subscription? Is it spying?" | Skeptical | Subscription fatigue, privacy doubt | One-time price, offline, zero telemetry — stated above the fold | Landing → download > 15 % |
| **3. Install** | Downloads, drags to /Applications, runs the installer | "How much setup is this?" | Impatient | Gatekeeper warning on an unsigned build; Accessibility prompt | One command; first-run screen explains each permission and why | Install completes > 80 % |
| **4. First win** | Right-clicks 5 files → Copy Paths → pastes into Claude Code | "Oh. That's it. That's the whole thing." | Relief | Feature buried in a nested submenu | Time-to-first-win < 60 s; the two headline actions are the first two menu items | First win < 60 s for > 70 % |
| **5. Habit** | Uses `paths`, `bundle`, `new`, `sandbox` dozens of times a day; binds `⌥⌘N` | "I don't remember how I worked before" | Reliant | Any command slower than doing it manually | < 300 ms every time; never a spinner | > 20 invocations/day by day 7 |
| **6. Advocate** | Posts a screenshot, tells their team | "Everyone running agents needs this" | Ownership | Nothing to share | Copy output carries no watermark — the *speed* is the pitch | > 1 referral per 10 users |

## Moments of truth
1. **The first right-click** — if Chute is not in the menu, the product does not exist.
2. **The first paste into an agent** — if the format is wrong, trust is gone permanently.
3. **The first destructive command** — if `unpack` or `clean` ever eats work, the user uninstalls and tells people. Hence dry-run by default.
